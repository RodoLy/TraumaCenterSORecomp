# Where this game keeps what WiiCompiled's native GX looks for at Mario Kart Wii's addresses.
# Dónde guarda este juego lo que el GX nativo de WiiCompiled busca en las direcciones de Mario Kart Wii.
#
# The columns are those of RKDEEB-os-addresses.txt; tests/test_wiicompiled_addresses.py checks every row.
# Las columnas son las de RKDEEB-os-addresses.txt.
#
# Carried over from the Animal Parade port with tools/port_addresses.py, then finished by hand where
# this game's older SDK differs; every row is checked by tests/test_wiicompiled_addresses.py.
# Pasado del port de Animal Parade con tools/port_addresses.py y terminado a mano donde el SDK más
# viejo de este juego cambia; cada fila la comprueba tests/test_wiicompiled_addresses.py.
#
# The big variables of GX sit in .bss in the same order and at the same distances as in Animal Parade:
# __GXData is 0x80 bytes after the FIFO object GXInit sets up, and GPFifo 0x600 after __GXData. This
# game never builds display lists, so their variables are not here.
#
# covers: runtime/src/hle/gx
