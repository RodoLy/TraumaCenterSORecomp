# Where this game keeps what WiiCompiled's native audio looks for at Mario Kart Wii's addresses.
# Dónde guarda este juego lo que el audio nativo de WiiCompiled busca en las direcciones de Mario Kart Wii.
#
# The columns are those of RKDEEB-os-addresses.txt; tests/test_wiicompiled_addresses.py checks every row.
# Las columnas son las de RKDEEB-os-addresses.txt.
#
# Carried over from the Animal Parade port with tools/port_addresses.py, then finished by hand where
# this game's older SDK differs; every row is checked by tests/test_wiicompiled_addresses.py.
# Pasado del port de Animal Parade con tools/port_addresses.py y terminado a mano donde el SDK más
# viejo de este juego cambia; cada fila la comprueba tests/test_wiicompiled_addresses.py.
#
# WiiCompiled runs AX translated and replaces what is below it (DSP and AI). Its DSP builds AX's task
# itself, so it needs the task, AX's microcode and the four callbacks the task points at. In this game
# __AXOutInitDSP (0x8015AC88) fills the task with the callbacks in the same order, but its DRAM is
# 0x50 bytes after the task and 0x2000 bytes long at DSP address 0, where Mario Kart Wii's is 0x40
# bytes at 0xCD2. The microcode is the old AX of the first Wii games (checksum 0xFA450138), which
# WiiCompiled's mixer already knows.
# En este juego la DRAM de la tarea es distinta (0x2000 bytes en la dirección 0 del DSP) y el
# microcódigo es el AX viejo de los primeros juegos de Wii (checksum 0xFA450138), que WiiCompiled ya
# conoce.
#
# covers: runtime/src/hle/audio

# ---------------------------------------------------------------- AXOut.c: the callbacks of AX's DSP task

0x80126948  0x8015AC14  __AXDSPInitCallback (the task's init_cb, at 0x28)  name
0x80126954  0x8015AC20  __AXDSPResumeCallback (res_cb, at 0x2C)         name
0x801269A8  0x8015AC74  __AXDSPRequestCallback (done_cb, at 0x30)       name
0x801269B8  0x8015AC84  the next function, four bytes long (req_cb, at 0x34); neither map names it  __AXOutInitDSP

0x802F8200  0x802F7FF0  the DRAM the task sends the DSP (0x60 bytes after the task there, 0x50 here)  __AXOutInitDSP
0x80385800  0x803A6F10  the DSP's start address for the microcode       __AXOutInitDSP
0x80385802  0x803A6F12  the DSP's resume address                        __AXOutInitDSP
0x80385804  0x803A6F14  the microcode's length                          __AXOutInitDSP

0x80386528  0x803A7D10  set by __AXDSPInitCallback once the DSP runs AX; __AXOutInitDSP waits on it  __AXDSPInitCallback
