# Mario Kart Wii.

# Las columnas son las de RKDEEB-os-addresses.txt.

# WiiCompiled's DVD reads the extracted folder, but it still sets the SDK's own flags so that what runs
# translated (DVDCancel, __DVDPrepareReset...) finds the drive idle. This game's dvd.c is newer than Mario
# Kart Wii's and has more variables, so its small ones are not at one distance from Mario Kart Wii's:
# each is found by what the code does with it, and two are not found yet (the runtime skips them in this
# game).
#
# covers: runtime/src/hle/storage
